# 書庫 MCP拡張機能（.mcpb）

Claude Desktopから、noteなどのブログバックアップを検索・閲覧できるようにする拡張機能です。

書庫アプリとは独立して動きます。アプリのインストールも起動も不要です。解析ロジックはアプリ（`Sources/WXRReader/WXRParser.swift`、`HTMLToMarkdown.swift`）からの移植なので、結果はアプリと一致します。

## インストール

1. [Releases](https://github.com/tanuu5/WXRReaderMac/releases) から `shoko.mcpb` をダウンロード
2. ダブルクリック（またはClaude Desktopのウィンドウにドラッグ＆ドロップ）
3. インストール画面で「バックアップフォルダ」に、noteのバックアップを展開したフォルダを指定
4. インストール

設定ファイル（`claude_desktop_config.json`）を手で編集する必要はありません。Claude Desktopが必要な設定を自分で書き込みます。

## バックアップを更新したとき

**何もしなくて構いません。** noteから取り直したバックアップでフォルダの中身を入れ替えるだけです。

ファイルの更新時刻とサイズが変わったことをサーバが検知して、次の検索から自動的に新しい内容を読みます。手元の実データ相当（10ファイル・約18MB・1008記事）で読み込みは約0.13秒なので、待たされる感覚はないはずです。

## 使用例

- 「書庫にClaude関係の記事どれくらいある?」
- 「去年書いたSwiftの記事を探して、内容をまとめて」
- 「『バイブコーディング』について前に何を書いたか教えて」
- 「2026年前半に書いた記事のタイトルを全部出して」

## なぜMCPなのか（1000本のブログを扱うために）

記事が1000本を超えると、Claudeにフォルダを渡して読ませる方式は成立しません。バックアップは記事ごとにファイルが分かれておらず、1つの.xmlに100記事ほどがまとまっているためです。1ファイル開いただけで約117万字、フォルダ全体では約1,178万字。1回の会話には到底収まりません。

この拡張機能では、18MBのXMLを読むのはサーバのプロセスで、Claudeに渡すのは検索でヒットした分だけです。実測値は次のとおり。

| 操作 | Claudeの文脈に入る量 |
| --- | --- |
| `library_info`（蔵書の概要） | 約260字 |
| `search_articles`（既定の20件） | 約5,000字 |
| `get_article`（記事1本の全文） | 約4,400字 |
| 参考：生の.xmlを1ファイル読む | 約1,168,000字 |

同じ検索がフォルダ直読みの約1,500分の1で済みます。これがMCPを挟む理由です。

`limit` の上限を50に抑えているのも同じ理由です。該当が多いときは全件を取ろうとせず、`date_from` / `date_to` / `tag` / `category` で絞るか、検索語を具体的にしてください。上限を超えた場合はサーバがその旨を応答に添えます。

## ツール

| ツール | できること |
| --- | --- |
| `library_info` | 記事数、期間、投稿タイプ、よく使うカテゴリ・タグの概要 |
| `search_articles` | 検索。スペース区切りでAND、`OR` でOR。カテゴリ・タグ・期間・投稿タイプで絞り込み |
| `get_article` | 記事1件の本文取得。`markdown` / `html` / `text` を選べる |

検索の意味論はアプリと同じです。タイトル・本文・カテゴリ・タグを部分一致（小文字化）で見ます。

なお、**noteのバックアップにはカテゴリ・タグが含まれていません**（エクスポート形式の仕様で、書庫アプリでも同様に空になります）。noteが元データの場合、`tag` と `category` での絞り込みは効きません。検索語と日付範囲（`date_from` / `date_to`）で絞ってください。WordPressのエクスポートには含まれるため、その場合は機能します。

## プライバシー

記事の内容がこの拡張機能から外部へ送信されることはありません。ファイルの読み取りのみを行い、書き込みも通信もしません。

（Claudeとの会話の中で記事の内容を扱えば、当然その部分はAnthropicのサーバへ送られます。これは拡張機能ではなくClaudeの利用そのものの話です。）

## 開発

依存パッケージはありません。Node標準ライブラリのみで動きます。

```bash
# 動作確認（読み込めるか、記事数は合っているか）
SHOKO_WXR_DIR=/path/to/backup node server/index.js --selftest

# .mcpb を作る
./pack.sh
```

`pack.sh` は `@anthropic-ai/mcpb` をnpx経由で呼び、`../build/shoko.mcpb` を出力します。

構成:

```
mcpb/
  manifest.json     # 拡張機能の定義（ツール一覧・フォルダ選択UIの定義）
  server/index.js   # MCPサーバ本体（WXR解析・検索・Markdown変換）
  icon.png
  pack.sh
```
